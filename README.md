# 🗣️ TalkTiles — Free Picture Communication for Everyone

A free, open-source AAC (Augmentative and Alternative Communication) app that works on any device, in any browser. No download, no account, no cost — ever.

🔗 **Live app:** https://kvoth215.github.io/TalkTiles/

---

## ✨ What It Does

- 🗣️ Tap pictures to build sentences the app speaks aloud
- ⭐ **Focus Mode** — clears the screen to just 2–5 large choices for students who need simplicity
- 🌐 **Library** — 25 research-backed vocabulary packs (Beukelman & Light, ASHA)
- ☁️ **Community Library** — teachers worldwide upload and share vocabulary modules
- 🍔 **Restaurant Menus** — full McDonald's and Red Robin menus with drill-down navigation
- ✏️ **Fully Customizable** — add photos, emoji, and custom categories in seconds
- 📲 **QR Code Sharing** — share vocabulary between devices instantly
- 💾 **Works Offline** — installs as a home screen app on any device
- 🆓 **Free Forever** — no subscription, no paywall, no catch

---

## ☁️ Community Library

Teachers anywhere in the world can now share their vocabulary modules:

1. Build a vocabulary set in TalkTiles
2. Click the **☁️ Share** button in the top bar
3. Fill in the title, subject, grade level, and language
4. Submit for review — once approved it appears in the Community Library worldwide

Every submission is reviewed before going live. Nothing is published without approval.

## 🛠️ For Developers

This is a single-file open-source app (`index.html`). Fork it, customize it, and contribute back!

- Add your own symbols to the `VOCAB` object
- Add new categories with `id`, `label`, `color`, `emoji`, and `symbols`
- Submit vocabulary packs via Pull Request

**Tech stack:** Vanilla HTML, CSS, JavaScript — no frameworks, no dependencies, no build step.
